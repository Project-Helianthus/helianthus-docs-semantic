# Native documentation owners

Protocol-neutral documentation links to native evidence; it does not absorb or
rewrite native protocol ownership.

| Native knowledge | Public documentation owner |
|---|---|
| eBUS and Vaillant wire behavior, profiles, and evidence | [`helianthus-docs-ebus`](https://github.com/Project-Helianthus/helianthus-docs-ebus) |
| eeBUS, SHIP, SPINE, use cases, pairing, and native evidence | [`helianthus-docs-eebus`](https://github.com/Project-Helianthus/helianthus-docs-eebus) |
| Modbus, SunSpec, and vendor profile evidence | [`helianthus-docs-modbus`](https://github.com/Project-Helianthus/helianthus-docs-modbus) |
| Generic CAN and SocketCAN behavior and profiles | [`helianthus-docs-canbus`](https://github.com/Project-Helianthus/helianthus-docs-canbus) |
| GREE VRF CAN/UART behavior and evidence | [`helianthus-docs-canbus/protocols/gree`](https://github.com/Project-Helianthus/helianthus-docs-canbus/tree/665a5f22f78c349b5e3063bda158af250a3f44b6/protocols/gree) |

Each semantic mapping must cite an exact native source/profile/version and state
its qualification and evidence. Unknown or restricted material remains unknown
or restricted; it is not reconstructed from a semantic target.
